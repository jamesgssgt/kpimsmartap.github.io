# 需要一個設定分子分母的頁面定義與定義指標公式

針對「手術照護指標」檔案，設計 **Next.js 分子分母設定頁面**，支援醫品人員視覺化定義 CQL 公式、ValueSet、排除條件，並一鍵生成 FHIR Measure + Library，可直接部署到 TWCore/HAPI。[^1]

## 分子分母設定頁面（`/settings/measure-builder`）

### 畫面結構（React Component）

```tsx
// app/settings/measure-builder/page.tsx
"use client";
import { useState } from 'react';

export default function MeasureBuilder() {
  const [measure, setMeasure] = useState({
    id: 'measure-proph-abx-1h',
    title: '預防性抗生素劃刀前1小時內給予比率',
    denominator: { expression: '', resources: [], conditions: [] },
    numerator: { expression: '', resources: [], conditions: [] },
    exclusions: { expression: '', resources: [], conditions: [] }
  });

  return (
    <div className="p-8 max-w-6xl mx-auto">
      <h1 className="text-3xl font-bold mb-8">指標公式建構器</h1>
      
      {/* 基本資訊 */}
      <MeasureHeader measure={measure} onChange={setMeasure} />
      
      {/* 分子分母定義區 */}
      <div className="grid grid-cols-3 gap-8 mb-8">
        <MeasurePopulation 
          title="分母" 
          type="denominator"
          population={measure.denominator}
          onChange={(p) => setMeasure({...measure, denominator: p})}
        />
        <MeasurePopulation 
          title="分子" 
          type="numerator"
          population={measure.numerator}
          onChange={(p) => setMeasure({...measure, numerator: p})}
        />
        <MeasurePopulation 
          title="排除" 
          type="denominator-exclusion"
          population={measure.exclusions}
          onChange={(p) => setMeasure({...measure, exclusions: p})}
        />
      </div>
      
      {/* CQL 預覽與生成 */}
      <CQLPreview measure={measure} />
      
      {/* 一鍵部署 */}
      <DeployButtons measure={measure} />
    </div>
  );
}
```


### 分子分母定義組件

```tsx
// components/MeasurePopulation.tsx
interface MeasurePopulationProps {
  title: string;
  type: 'denominator' | 'numerator' | 'denominator-exclusion';
  population: any;
  onChange: (population: any) => void;
}

export function MeasurePopulation({ title, type, population, onChange }: MeasurePopulationProps) {
  return (
    <div className="border rounded-lg p-6 shadow-sm">
      <h3 className="text-xl font-semibold mb-4 text-blue-600">{title}</h3>
      
      {/* FHIR Resource 選擇 */}
      <div className="mb-4">
        <label className="block text-sm font-medium mb-2">FHIR 資源</label>
        <select 
          multiple 
          className="w-full p-2 border rounded"
          value={population.resources}
          onChange={(e) => onChange({
            ...population, 
            resources: Array.from(e.target.selectedOptions, option => option.value)
          })}
        >
          <option value="Encounter">Encounter (就診事件)</option>
          <option value="Procedure">Procedure (手術)</option>
          <option value="Observation">Observation (觀察)</option>
          <option value="MedicationAdministration">MedicationAdministration (給藥)</option>
          <option value="Patient">Patient (病患)</option>
          <option value="Condition">Condition (診斷)</option>
        </select>
      </div>

      {/* 條件建構器 */}
      <ConditionsBuilder 
        conditions={population.conditions}
        onChange={(conditions) => onChange({...population, conditions})}
      />

      {/* CQL 語法提示 */}
      <div className="mt-4 p-3 bg-gray-50 rounded">
        <code className="text-sm text-green-700">
          CQL 範例: [{population.resources[^0] || 'Resource'}: {type === 'denominator' ? 'surgery' : 'antibiotic-1h'}]
        </code>
      </div>
    </div>
  );
}
```


### 條件建構器（視覺化 CQL）

```tsx
// components/ConditionsBuilder.tsx
export function ConditionsBuilder({ conditions, onChange }: any) {
  const conditionTemplates = [
    { label: 'ICD-10-PCS 手術碼', fhirPath: 'Procedure.code', valueSet: 'ICD10PCS-00.30-86.99' },
    { label: 'ASA 分級', fhirPath: 'Observation.code=ASA', valueSet: 'TW-ASA' },
    { label: '手術室位置', fhirPath: 'Procedure.location', valueSet: 'TW-OR-LOCATION' },
    { label: '劃刀前60分', fhirPath: 'MedicationAdministration.effective 60m before Procedure.start', valueSet: '' },
    { label: '預防性抗生素', fhirPath: 'MedicationAdministration.category=prophylactic', valueSet: 'ATC-J01-PPX' },
    { label: '排除剖腹產', fhirPath: 'not Procedure.code in CesareanSection', valueSet: 'C-SECTION' }
  ];

  return (
    <div>
      <label className="block text-sm font-medium mb-2">條件定義</label>
      <div className="space-y-2 max-h-40 overflow-y-auto">
        {conditions.map((condition: any, index: number) => (
          <ConditionRow 
            key={index}
            condition={condition}
            templates={conditionTemplates}
            onUpdate={(updated) => {
              const newConditions = [...conditions];
              newConditions[index] = updated;
              onChange(newConditions);
            }}
            onDelete={() => {
              const newConditions = conditions.filter((_: any, i: number) => i !== index);
              onChange(newConditions);
            }}
          />
        ))}
        <button 
          className="text-blue-500 hover:text-blue-700 text-sm"
          onClick={() => onChange([...conditions, { label: '', fhirPath: '', valueSet: '' }])}
        >
          + 新增條件
        </button>
      </div>
    </div>
  );
}
```


### CQL 即時預覽

```tsx
// components/CQLPreview.tsx
export function CQLPreview({ measure }: { measure: any }) {
  const generateCQL = () => {
    const denomCQL = measure.denominator.resources.map(r => `[${r}]`).join(' ') + 
                    measure.denominator.conditions.map(c => `where ${c.fhirPath}`).join(' and ');
    
    const numCQL = measure.numerator.resources.map(r => `[${r}]`).join(' ') + 
                  measure.numerator.conditions.map(c => `where ${c.fhirPath}`).join(' and ');

    return `
library ${measure.id.replace('measure-', '')}CQL

define "Denominator":
  ${denomCQL}

define "Numerator":
  "Denominator" P
  ${measure.numerator.conditions.map((c: any) => `where ${c.fhirPath}`).join(' and ')}

define "${measure.title}":
  Count("Numerator") / Count("Denominator") * 100 '%'
    `;
  };

  return (
    <div className="border rounded-lg p-6 mb-8">
      <h3 className="text-lg font-semibold mb-4">CQL 即時預覽</h3>
      <pre className="bg-gray-900 text-green-400 p-4 rounded text-xs overflow-auto max-h-96 font-mono">
        {generateCQL()}
      </pre>
      <div className="mt-4 text-sm text-gray-600">
        FHIR Measure ID: <code>{measure.id}</code>
      </div>
    </div>
  );
}
```


### 一鍵部署按鈕

```tsx
// components/DeployButtons.tsx
export function DeployButtons({ measure }: { measure: any }) {
  const deployToFHIR = async () => {
    // 生成 FHIR Measure JSON
    const measureJson = {
      resourceType: 'Measure',
      id: measure.id,
      title: measure.title,
      library: [`Library/${measure.id.replace('measure-', '')}CQL`],
      group: [{
        population: [
          { id: 'denominator', criteria: { expression: 'Denominator' }},
          { id: 'numerator', criteria: { expression: 'Numerator' }}
        ]
      }]
    };

    // 部署到 HAPI FHIR
    await fetch('http://localhost:8080/fhir/Measure/' + measure.id, {
      method: 'PUT',
      headers: { 'Content-Type': 'application/fhir+json' },
      body: JSON.stringify(measureJson)
    });

    alert('部署成功！可至 http://localhost:8080/fhir/Measure 檢視');
  };

  return (
    <div className="flex gap-4">
      <button 
        className="bg-blue-600 text-white px-8 py-3 rounded-lg hover:bg-blue-700"
        onClick={deployToFHIR}
      >
        🚀 部署到 FHIR Server
      </button>
      <button className="bg-green-600 text-white px-8 py-3 rounded-lg hover:bg-green-700">
        💾 下載 JSON 檔案
      </button>
      <button className="bg-purple-600 text-white px-8 py-3 rounded-lg hover:bg-purple-700">
        📊 執行計算
      </button>
    </div>
  );
}
```


## 使用情境示範（預防性抗生素指標）

**步驟 1**：選擇「預防性抗生素劃刀前1小時內給予比率」

**步驟 2**：分母設定

```
FHIR 資源: [x] Procedure, [x] Observation, [x] MedicationAdministration
條件:
- [x] ICD-10-PCS 手術碼 (00.30-86.99)
- [x] ASA 分級
- [x] 手術室位置
- [x] 有預防性抗生素給藥
```

**步驟 3**：分子設定

```
條件:
- [x] 預防性抗生素給藥時間在劃刀前60分鐘內
```

**步驟 4**：排除設定

```
條件:
- [x] 排除剖腹產
- [x] 排除 Vancomycin/FQ 預防性使用
- [x] 排除手術前治療性抗生素
```

**即時 CQL 預覽**：

```cql
define "Denominator":
  [Procedure] [Observation] [MedicationAdministration] 
  where Procedure.code in "ICD10PCS-00.30-86.99" 
    and Observation.code=ASA 
    and Procedure.location in "TW-OR-LOCATION"
    and MedicationAdministration.category=prophylactic

define "Numerator":
  "Denominator" P where MedicationAdministration.effective 60m before Procedure.start
```

**一鍵部署** → 生成 FHIR Measure → HAPI 自動計算！
